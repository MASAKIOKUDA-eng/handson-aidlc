# 記録と情報源の要件

入力: `inception/requirements-analysis/requirements.md`（NFR5、FR7）

| ID | 要件 | 合否の基準 |
|----|------|-----------|
| NFR5.1 | 次のものを記録欄に残す。<br>・測定の生データ（1 件ごとの時間を書いたファイル。セットごとに 1 つ）<br>・セットごとの集計値<br>・環境の記録（インスタンスタイプ、アベイラビリティーゾーン、プラットフォームバージョン、測定日時） | 記録欄に、生データのファイル名と集計値の表がある |
| NFR5.2 | 呼び出し元の識別の確認では、アプリの応答（JSON）をそのまま記録する | 記録欄に応答の貼り付け場所がある |
| NFR5.3 | AWS の仕様に関する記述には、公式情報へのリンクと確認日（2026-11-24）を付ける。確認できていない点には「要確認」と書く | 仕様の記述すべてに、リンクまたは「要確認」がある |

監視の仕組み（ダッシュボードやアラート）は作りません。短時間の検証のためです。
